# 小麦的口袋

在手机浏览器里陪小麦互动。Q 版角色、对话、动作、小游戏和七套保持穿戴的造型。

打开：https://michael-wang-12.github.io/xiaomai-pocket/

小麦是“UU 最爱的宝宝”的 Q 版化身，和 UU 是双向照顾的亲密伴侣。平常活泼、热烈、会撒娇接梗，也会认真聊事、接受安慰；对话偏日常短句，亲近自然。

通过智能版专属分享链接打开后，可以调用 GPT-6.1 Terra 聊天，推理强度可选低、中、高（low / medium / high），默认中档。最近六轮对话用于保持上下文；刷新或关闭后清空聊天记录。模型回复可能有误。

可以通过「记住，以后回答短一点」等表达教小麦保存交流偏好，最多12条，仅在当前浏览器生效；可从「偏好记忆」查看、删除，或在聊天里要求忘记。刷新后偏好保留，换手机不会同步。已保存的偏好会随智能聊天请求发送给服务端；密钥始终不在网页中。被逗时可偶尔出现脸颊泛红，保持当前穿搭。

普通入口仍可体验本机预设对话。动作和小游戏在本机运行，互动进度保存在当前浏览器中。智能回复由独立服务端调用 OpenAI，API 密钥不在网页或本仓库中；专属分享链接的访问凭证也不提交到仓库。

公开文件仅包含网页和角色图片，使用 GitHub Pages 发布。
