# 小麦的口袋

在手机浏览器里陪小麦互动。Q 版角色、对话、60 种互动、8 个小游戏，黑色长风衣、简约皮夹克、飞行员皮衣、黑衬衫与七种配饰造型。

当前版本 **v8.7.1**。在「设置 → 关于小麦」查看版本、更新日期和每个版本的更新内容；最近一次更新默认展开。早期未单独标版本的更新合并记录在「初始上线」。

打开：https://michael-wang-12.github.io/xiaomai-pocket/

小麦是“UU 最爱的宝宝”的 Q 版化身，和 UU 是双向照顾的亲密伴侣。平常活泼、热烈、会撒娇接梗，也会认真聊事、接受安慰；对话偏日常短句，亲近自然。

通过智能版专属分享链接打开后，可以调用 GPT-6.1 Terra 聊天，推理强度可选低、中、高（low / medium / high），默认中档。最近六轮完整对话用于保持上下文。所有设备打开普通网址就能接着使用 UU 原有的聊天、偏好、穿搭和成长进度。无需登录，设备数量不限。能访问该网址的人可以查看、更改和清空其中的记录。聊天默认保留最近 30 天，最多 200 条，可选 7 天、一直保留或仅本次打开。选择仅本次或清空聊天，会清除云端聊天。原始照片不进入存档。模型回复可能有误。

可以通过「记住，以后回答短一点」等表达教小麦保存交流偏好，最多 12 条，可在所有设备间同步；可从「偏好与例句」查看、删除，或在聊天里要求忘记。换手机仍会参考同一组偏好和已教的例句。已保存的偏好会随智能聊天请求发送给服务端；密钥始终不在网页中。被逗时可偶尔出现脸颊泛红，保持当前穿搭。

新版会在生成过程中逐步显示回复。只有完整成功的回复会加入本次上下文，并应用动作与偏好记忆；中断时会显示失败提示，不自动重试。日常聊天可选低档减少推理等待，实际速度仍受网络和当次生成影响。

普通入口仍可体验本机预设对话。动作和小游戏在本机运行。手机、平板和电脑通过普通网址同步穿搭、场景、成长手记和互动进度。在「设置 → 设备同步」查看状态或立即同步。「立即同步」在首次打开时也可以使用。智能回复由独立服务端调用 OpenAI，API 密钥不在网页或本仓库中；专属分享链接的访问凭证也不提交到仓库。

公开文件仅包含网页和角色图片，使用 GitHub Pages 发布。

可对已完成的回复点“教这句”或在聊天记录里长按，修改为认可的接话方式。最多保留6组例句，可查看、修改或删除；后续智能聊天会参考相似场景，属于提示与例句学习，不是模型权重训练。未完成的流式回复不写入聊天上下文，也不自动重试。

高频互动和对话反应使用多阶段姿态组合，同一种互动避免连续播放相同组合。支持轻微害羞、惊讶、得意、认真听与分阶段脸红；动作使用当前穿搭的完整图集，可被新动作或换装中断。减少动画设置可保留静态反应。

主动搭话可在设置选择安静、偶尔、活泼。只在前台空闲时使用本地台词，输入、回复、照片准备或弹窗期间暂停，不额外请求模型。

输入框左侧＋号可选相册或相机，预览确认才发送；照片压为最长边1280/700KB JPEG，使用现有模型和API额度。原图不进入聊天存档，默认只用于本条，可自愿在本次打开内续聊10分钟并随时移除。

动作后的害羞、得意等有短暂余韵及渐隐，脸红只保留安静的低头/泛红姿态，没有竖拇指或夸张惊讶。

UU 准备好时，打开「设置 → 连接微信 → 获取二维码」。可以用微信扫码，也可以在同一部手机点击「打开微信官方绑定入口」。页面会核对微信授权结果，码过期后可重新获取。微信收发需要独立接入服务在线。网页聊天在设备间同步，微信对话仍由接入服务单独保存。

穿搭页可以直接预览并切换黑色长风衣、简约皮夹克、飞行员皮衣、黑衬衫整套衣服；三套新衣服都有完整互动、照顾、表情和16个转身方向。选定后聊天、动作及刷新都会保留当前衣服。衣服和配饰独立选择，鸭舌帽、头戴耳机、墨镜、黑围巾、小王冠、小花胸针和派对帽可搭配全部四套衣服。帽子/耳机/王冠/派对帽同属头部槽，选一件；墨镜、围巾和胸针可另加。再点已选配饰只摘下这一件，换衣服不清除其他配饰。

新增三套衣服均为 All Black：内搭、裤子、鞋面和鞋底统一黑色，用皮革、棉布与光泽区分层次。

「配饰造型 → 领带」提供黑衬衫专属的「打上领带 / 解下领带」开关。切换其他衣服时保留领带偏好、暂停穿戴；换回黑衬衫后恢复。系上后互动、转身、聊天和刷新都保持，模型也会收到当前实际穿着的衣服与配饰。

「穿搭」内通过「换衣服 / 配饰造型」两个选择栏切换。换衣服显示四套整套造型，配饰造型按头部、可叠加配饰与领带分组；单纯切换选择栏不改变正在穿的搭配。旧存档中的整套配饰会自动迁移为黑色长风衣和对应配饰。
